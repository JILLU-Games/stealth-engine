# docs/

**Purpose:** Engine-level usage guidelines and technical reference for stealth_engine. Committed to git. Always kept current.

## What lives here

Complete A–Z reference documentation for every feature and module. This folder answers:
- What each feature does
- Why it exists
- How it works internally
- Where it lives in the codebase
- When it activates
- How to use it correctly

## Rules

- **No detail may be omitted.**
- **All information must be real and exact** — no guesses, no placeholders, no stale content.
- Updated whenever engine behaviour changes, in the same commit as the code change.
