# Feature U: Uniform error model

**Status:** Implemented (v0.1.0)  
**Primary module(s):** `exceptions.py`

## Description

All exceptions inherit from StealthEngineError. Callers catch one base type. Six typed subclasses cover config, identity, proxy, session, launch, and automation errors.
