# stealth-engine v0.4.0 — Core Preview

This is a prepared prerelease candidate, not a stable production certification. Publication is separately authorized only after exact main CI acceptance. Historical v0.3.0 remains unchanged.

## Maintenance and SDK changes since v0.3.0

- Optional synchronous/asynchronous lifecycle callbacks; shared close completion and owner-only cleanup.
- Early closure handling during initialization, serialized state exports, and stop-once worker shutdown.
- Existing filesystem operations offloaded from async launch and session maintenance; no claim that every SDK call is nonblocking.
- Backward-compatible configuration defaults; explicit same-profile snapshot restore is opt-in, replaces state rather than merging it.
- Hash-locked package CI, independent wheel/sdist installs, and runner dependency-source isolation.
