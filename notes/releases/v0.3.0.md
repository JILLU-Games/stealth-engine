# stealth-engine v0.3.0 — Core Preview

**Scope:** Core direct-host Python engine. This is a **prerelease** and is **not** full external-proxy certification.

- Windows/Linux clean Python package installation, profile lifecycle and secure config exports
- Real Camoufox smoke, fingerprint readback, stable 2D canvas, WebGL and tracker-routing acceptance

## Package & installation

The primary distribution is `stealth_engine-0.3.0-py3-none-any.whl`. The `.tar.gz` source distribution is included for MIT open-source compliance and build reproducibility investigations. Python 3.10+ is required. On a clean environment:

```sh
python -m pip install stealth_engine-0.3.0-py3-none-any.whl
python -m camoufox fetch
```

Camoufox/Firefox and browser runtime dependencies are installed or fetched separately; **this is not a Windows EXE**, standalone browser binary or compiled PYD module. Windows/Linux releases use the same pure-Python wheel. Verify `SHA256SUMS.txt` before use.

## Explicit limitations

- **UNVERIFIED:** live third-party HTTP/SOCKS proxy egress, external proxy credentials, remote DNS and proxy-specific WebRTC/IP leakage. Synthetic localhost proxy testing is not a substitute.
- **UNVERIFIED:** DNS/WebRTC leak safety across arbitrary networks, full browserforge-to-Camoufox fingerprint parity, arbitrary end-user Windows ACL policies and all external target websites.
- `js_noise` is experimental and may be detectable. No anti-bot or undetectability guarantee is made.
- Per-profile logging sanitization covers profile-owned records; module-global Loguru handlers do not implement the same profile-level isolation contract.
- Video/CDP-only features remain unsupported for the Camoufox/Firefox backend.
- `DEPENDENCY_SNAPSHOT.txt` records the release build environment; it is **not** a portable, fully locked dependency graph across all OS/Python combinations.
- Changes to supported dependencies or runtimes after this prerelease require another validated build.
